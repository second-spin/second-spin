# Second Spin — International-style website redesign

**Tagline:** Share the Gear. Spread the Joy.  
**Design direction:** Editorial, minimal, community-first, mobile-responsive.

## Files
- `index.html` — complete responsive landing page
- `styles.css` — layout, typography, colour system and responsive rules
- `script.js` — mobile menu, working category/search filters, informational preview notices
- `favicon.svg` — brand icon
- `.nojekyll` — static hosting helper

## Publish the redesign to your existing GitHub Pages site

1. Download and extract this ZIP.
2. Open your existing repository: https://github.com/second-spin/second-spin
3. Choose **Add file → Upload files**.
4. Upload/drag the five files from this folder into the repository root. If GitHub asks to replace files with the same names, confirm.
5. In the commit message, enter `Redesign Second Spin website`.
6. Click **Commit changes**.
7. Wait a few minutes, then refresh https://second-spin.github.io/second-spin/ with Ctrl+F5.

Your existing Pages settings should remain unchanged.

## Important functionality status
This is a static website. The navigation and category/search filters work. Category buttons show an informational notice only. There is no real donation database, listing moderation, account system, contact form, or request submission backend yet. Do not advertise example categories as currently available items. Connect real Google Forms (or another trusted form service) before collecting submissions. Keep responses private and do not commit personal data to this public repository.
